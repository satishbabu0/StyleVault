# 👗 StyleVault – AI Fashion Ecommerce Platform

StyleVault is a modern React-based ecommerce fashion platform designed to provide a smooth and interactive online shopping experience. The project includes advanced ecommerce features such as cart management, checkout system, PhonePe QR payments, and a virtual fit room concept.

🌐 **Live Demo:**
https://style-vault-rose.vercel.app/

📂 **GitHub Repository:**
https://github.com/satishbabu0/StyleVault

---

# 🚀 Features

✅ Add to Cart functionality
✅ Buy Now option
✅ Checkout Page
✅ PhonePe QR Payment Integration
✅ Responsive Modern UI
✅ Product Quantity Management
✅ Remove from Cart

# ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/satishbabu0/StyleVault.git
```

Move into project folder:

```bash
cd StyleVault
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```

Open browser:

```bash
http://localhost:3000
```
